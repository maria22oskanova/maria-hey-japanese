Одна мысль — разные источники

雨が降りそうです。
Судя по небу, вот-вот пойдёт дождь.
明日は雨が降るそうです。
Говорят (по прогнозу), завтра дождь.

Обе фразы — о дожде. Но в первой ты делаешь вывод по тому, что видишь, а во второй передаёшь информацию, которую услышала или прочитала.

Здесь мы изучим две разные формы そうだ, затем сравним их с ようだ・みたいだ・らしい. Последние три частично выходят за рамки разных учебных списков N4, но полезны для уверенного уровня и перехода к N3.
ぶんぽう

Четыре конструкции

1. ～そうだ · внешние признаки（様態）

雨が降りそうです。

По видимым признакам кажется, что действие вот-вот произойдёт. Для глагола: основа ます без ます + そうです. Для い-прилагательного: без い + そうです (おいしい → おいしそう). Для な-прилагательного: основа + そうです (元気 → 元気そう).

このケーキはおいしそうです。 — Этот торт выглядит вкусным.

彼は元気そうです。 — Он выглядит бодрым.

Особые формы: いい → よさそう、ない → なさそう. Не говорим 降るそうです для значения «вот-вот пойдёт».

2. ～そうだ · передача информации（伝聞）

明日は雨が降るそうです。

«Говорят, что…»; информация получена извне. Используй простую форму перед そうです: глагол 降るそうです, い-прилагательное おいしいそうです, な-прилагательное 元気だそうです, существительное 学生だそうです.

ニュースによると、明日は寒いそうです。 — По новостям, завтра будет холодно.

Для передачи слуха не надо превращать прилагательное おいしい в おいしそう: значения будут разными.

3. ～ようだ · вывод по признакам

誰もいないようです。

«Похоже / судя по всему…». Говорящий делает вывод по данным или ситуации; стиль относительно нейтральный и более книжный, чем みたいだ.

電気が消えています。もう寝たようです。 — Свет выключен. Видимо, уже легли спать.

Присоединение: глагол/い-прилагательное в простой форме + ようだ; な-прилагательное + なようだ; существительное + のようだ.

4. ～みたいだ · «похоже», разговорный вариант

この店は人気があるみたいです。

Обычно звучит более разговорно, чем ようだ. Может выражать вывод по ситуации или сходство.

あの人は先生みたいです。 — Тот человек, похоже, учитель / похож на учителя.

Присоединение: простая форма глагола/прилагательного + みたいだ; существительное или な-прилагательное без だ + みたいだ.

5. ～らしい · слух или типичность

駅の近くに新しいカフェができたらしいです。

«Похоже / по имеющейся информации…». Часто вывод или слух из непрямых источников; говорящий не обязательно может назвать конкретный источник. Кроме того, после существительных らしい может обозначать типичность: 子どもらしい — по-детски естественный.

彼は風邪をひいたらしいです。 — Похоже, он простудился.

Если хочешь явно передать слова конкретного источника, обычно удобнее そうだ（伝聞）.

Как выбрать форму?

ФормаГлавная идеяПример
降りそうВижу признаки, скоро начнётся空が暗い。雨が降りそう。
降るそうМне сообщили / прочитала天気予報によると、雨が降るそう。
降るようДелаю вывод по обстоятельствам外が暗いので、雨が降るようだ。
降るみたいПохоже, разговорный вывод午後は雨が降るみたい。
降るらしいСлышала / косвенные сведения午後は雨が降るらしい。

Сравнение на одной ситуации

この店のケーキはおいしそうです。
По виду он вкусный.

この店のケーキはおいしいそうです。
Говорят, этот торт вкусный.

この店のケーキはおいしいみたいです。
Похоже, торт вкусный.

Важно: ようだ・みたいだ・らしい могут пересекаться. В заданиях ниже всегда будет контекст, который делает один вариант наиболее естественным, а не просто единственным грамматически возможным.

Письменная практика

Напиши четыре предложения: одно по внешним признакам, одно со ссылкой на услышанную информацию, одно с предположением и одно с разговорным みたい.
